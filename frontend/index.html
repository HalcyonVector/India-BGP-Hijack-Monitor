About

Checks live BGP announcements for India's largest ISPs against a daily baseline and RPKI, keeps a captured history, and is tested on archived real incidents. For personal and educational use, not an authoritative source on Indian routing.

Source code and method on GitHub

Data

  • RIPE RIS Live: real-time BGP updates
  • RIPEstat Data API: announced prefixes, RPKI validation, AS holders
  • RIPE RIS raw data: archived updates for the incident replay
  • Captured history and baseline history (committed by CI)

References
